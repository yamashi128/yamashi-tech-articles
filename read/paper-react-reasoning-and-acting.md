# ReActを読む：AIの行動を、実行結果で修正する仕組み

[掲載ページ](https://yamashi-tech.com/articles/paper-react-reasoning-and-acting) · [原稿データ](../articles/paper-react-reasoning-and-acting.json)

公開: 2026-09-17 / 更新: 2026-10-23 / 確認: 2026-10-23

ReActは、次の行動を考え、道具を使い、その結果から計画を直す手法だ。検索と推論を組み合わせる仕組みを、HotpotQA・FEVERの比較と失敗例から読み解く。

## AIに必要なのは、実行結果を見て計画を直すこと

ReActが提案したのは、AIに答えを一度で作らせる代わりに、行動の結果を受け取って次の判断を変える進め方だ。調べる対象を決める、検索する、見つかった事実を読む、足りなければ検索し直す。この循環を、推論と外部操作を組み合わせた一つの手法として示した。

たとえば人物の出身地を問われたとき、名前から答えを推測するだけでは同姓同名を取り違える。検索結果を読んで別人だと分かれば、所属や年代を手掛かりに調べ直せる。ReActの強みは、この修正を一回の作業の途中に入れられる点にある。

## 考える・操作する・観察するを繰り返す

論文では、次に何をするかを考えるThought、外部に働きかけるAction、環境から返るObservationを組み合わせる。Thoughtはモデルが生成する記述で、外部の事実ではない。検索結果や環境の状態をObservationとして戻すことで、推測と観測を区別して作業を進める。

質問応答の実験に用いた操作は、Wikipediaの記事を探すsearch、記事内の語を探すlookup、回答を確定するfinishの三つ。HotpotQAでは6例、FEVERでは3例の作業例を提示した。複雑なツール群を用意するより、必要な情報を取得し、その結果で次の操作を選べる形にした。

検索作業の流れを示す概念例（実行結果ではない）

```text
問い: AとBは同じ都市の出身か
判断: それぞれの出身地が必要
操作: Aの公式プロフィールを取得
観察: 出身地はX市
操作: Bの公式プロフィールを取得
観察: 出身地はY市
回答: 二つの出典を添えて比較する
```

## 検索を足すと、得意な問題と苦手な問題が変わる

PaLM-540Bを使った論文のTable 1では、FEVERの正解率は推論だけのCoTが56.3%、ReActが60.9%だった。一方、複数の資料をつなぐHotpotQAの完全一致率は29.4%から27.4%へ下がった。外部情報に接続するだけで、すべての問題が改善する結果ではなかった。

CoTは途中の推論を生成する手法、CoT-SCは複数の推論結果を使う手法だ。ReActとCoT-SCを切り替える構成では、HotpotQAで35.1%、FEVERで64.6%を報告した。外部で調べる処理と、集まった情報をまとめる処理を組み合わせた点が、この比較の読みどころになる。

論文Table 1。PaLM-540Bによる当時の質問応答・事実検証実験

| 手法 | HotpotQA 完全一致率 | FEVER 正解率 |
| --- | --- | --- |
| CoT | 29.4% | 56.3% |
| ReAct | 27.4% | 60.9% |
| ReAct → CoT-SC | 35.1% | 62.0% |
| CoT-SC → ReAct | 34.2% | 64.6% |

## 検索の失敗を、次の行動へ返せるか

著者がHotpotQAの軌跡を分析した範囲では、失敗例に占める幻覚の分類はCoTが56%、ReActが0%だった。ただし、ReActの失敗には検索結果の問題が23%、推論の誤りや同じ操作から抜けられない問題が47%あった。この0%は抽出した失敗例の分類であり、ReAct全体の誤情報率を表す数字ではない。

操作環境のALFWorldとWebShopでも実験し、1〜2例の提示で、それぞれ従来の模倣学習・強化学習手法を成功率で34ポイント、10ポイント上回る結果を報告した。質問応答の完全一致率とは別の評価だが、状況を観察して計画を変える仕組みが、行動を伴う課題でも役立つことを示した。

## 実装するなら、ツールの返答と停止条件を設計する

編集部が実装へ持ち帰りたいのは、長い思考文より、次の判断に使える返答を用意することだ。検索なら該当なしと取得失敗を分け、ファイル操作なら適用した差分を返す。「検索した」という行動の記録だけでは、必要な情報を得たか判断できない。

同じ検索語と空の結果が続くなら、検索範囲を変えるか作業を止める。回答を終える条件も「もっともらしい文ができた」ではなく、「問いに必要な情報と出典がそろった」と定める。ReActは、観察が次の操作を変えるときに力を発揮する。

## 制約と未検証範囲

- 数値は論文中のモデル・プロンプト・データセットにおける著者の報告。編集部は再実験していない。
- 検索結果も誤り得る。外部情報の取得と、その情報が回答の根拠になるかの評価は別に必要。
